# E-Comm Template

A directory of independently maintained storefront, service, and venue templates.

[Open the live hub](https://teddexter0.github.io/e-comm-template/)

| Project | Live demo | GitHub |
| --- | --- | --- |
| Car Wash | [Open demo](https://rupa-mall-car-wash.vercel.app) | [Source](https://github.com/teddexter0/car_wash_Template) |
| Merch Store | [Open demo](https://clothes-store-fawn.vercel.app) | [Source](https://github.com/teddexter0/merch_store_template) |
| Dental Practice | [Open demo](https://dentist-template-one.vercel.app) | [Source](https://github.com/teddexter0/dentist_template) |
| Optician | [Open demo](https://optician-template.vercel.app) | [Source](https://github.com/teddexter0/optician_template) |
| Photography | [Open demo](https://photograph-store.vercel.app) | [Source](https://github.com/teddexter0/photography_store_Template) |
| Rupa Mall | [Open demo](https://rupa-mall-website.vercel.app) | [Source (private)](https://github.com/teddexter0/rupaMallWebsite) |
| Restaurant | [Open demo](https://restaurant-template-uhmf.vercel.app) | [Source](https://github.com/teddexter0/restaurant_template) |

To add the hub to your home screen, open it in Safari on iPhone and choose **Share → Add to Home Screen**. On Android, open Chrome’s menu and choose **Install app** or **Add to Home screen**.

The hub is a static site served from `docs/` on GitHub Pages.
